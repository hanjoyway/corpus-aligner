# 平行语料对齐工作台 · 单机版

汉英平行语料的加工工具：把一篇中文和它的英文译文（或中英交替排版的一份文档）
切成句子、自动配对，再在网页界面上逐行核对、修改，最后导出成翻译记忆库、
Excel、双语对照 Word/RTF 等常见格式。

界面是网页，但程序跑在自己电脑上——双击打开，浏览器自动弹出工作台，
关掉窗口就退出。不需要账号，不需要联网，语料不出本机。

---

## 一、装与用

### 直接用打包好的程序

| 系统 | 文件 | 打开方式 |
|---|---|---|
| Windows | `CorpusAligner.exe` | 双击。头一次启动要解压，慢几秒 |
| macOS | `CorpusAligner.app` | **右键 →「打开」**，再点一次「打开」 |

> macOS 上必须用右键打开：这个程序没有花钱买苹果的开发者签名，直接双击会被
> 系统拦下来说「无法验证开发者」。右键打开确认一次之后，以后双击就行。

程序启动后会打开 `http://127.0.0.1:5099`。如果浏览器没自动弹出来，
照着控制台窗口里印的地址手动打开即可。

### 从源码运行

```bash
pip install -r requirements.txt
python -m desktop.main
```

## 二、四步流程

工作台顶部的流程条对应四个步骤，可以从任意一步进入。

**1. 取得文本.** 已经是 txt 就直接粘贴或导入。扫描件 PDF 走「OCR · 图文校对」，
逐页显示左图右文，识别错的字当场改。

**2. 清洗.** 去掉页眉页脚、页码、脚注编号、markdown 标记。哪些规则生效可以自己勾。

**3. 对齐.** 两种输入方式：
- *双文档*——中文一栏、英文一栏，各自独立
- *单文档*——中英交替排版的一份文档，程序按段落的汉字比例自动分成两路

**4. 校对与导出.** 双列逐行显示，可以拆分、合并、上移、下移、插入空行、删除，
原文译文都能直接改字，每步都可撤销。导出格式：

| 格式 | 用途 |
|---|---|
| `.tmx` | 翻译记忆库，可导入 Trados / memoQ |
| `.xlsx` | Excel 双列 |
| `.docx` | 上下对照 Word |
| `.rtf` | 左中右英双栏对照（ABBYY Aligner 同款版式） |
| `.txt` | 左右对照 / 上下对照 / BFSU 双文件逐行 |
| 建库四件套 | `N_c.txt` + `N_e.txt` + `N_c.rtf` 打包 |

工作过程每隔几秒自动存进浏览器本地，意外关闭后重开会问要不要接着改；
也可以导出 `.json` 工程存档，换台电脑接着做。

## 三、对齐是怎么算的

两档，程序按有没有配密钥自动选，顶栏会标明当前用的是哪一档。

### 离线档（默认，不联网）

Gale & Church (1991) 的长度对齐。原理是：译文长度和原文长度大致成正比，
偏差近似正态分布，所以「这段中文对不对得上这段英文」可以纯靠字数算出来。
比例不写死，由当前这篇文档自己估（英文字符总数 ÷ 中文字符总数）——
不同文体差别很大，写死反而不准。

在此基础上加了一层**锚点**：两侧都出现的数字和全大写缩写（`2022`、`WTO`）。
对齐对了，它们本来就该同时出现在配对的两句里。

### 语义档（需要 SiliconFlow 密钥）

用 bge-m3 把中英句子映射到同一个向量空间，直接算跨语言的语义相似度。
遇到增译、删译、语序大幅调整时比长度法准得多。

### 两档共用的搜索

都用动态规划在全篇范围内找总分最高的一种切分方式，允许的配对比例从 1:1
一直到 1:5 / 5:1（中文意合长句常常对应好几句英文，反之亦然），合并会扣一点分，
免得算法为了凑高分把句子无限往一起并。

万一两侧句数悬殊到动态规划走不到终点，程序会退回逐句 1:1 配对、多出来的一侧
留单边空行——**宁可给出一个明显需要人工修的结果，也不静默丢句**。

## 四、密钥（可选）

三项功能要调外部模型服务，在工作台右上角「设置 · API Key」里填：

| 服务 | 管什么 | 不填会怎样 |
|---|---|---|
| SiliconFlow | 语义对齐（bge-m3） | 自动改用离线长度对齐 |
| DeepSeek | AI 校验、AI 重对齐 | 这两个按钮不可用 |
| 智谱 GLM | 扫描件 OCR | 只能处理已有文本 |

密钥保存在自己电脑的用户目录里，不在程序包内，也不上传到任何地方：

- Windows `%APPDATA%\CorpusAligner\settings.json`
- macOS `~/Library/Application Support/CorpusAligner/settings.json`

> AI 校验只做判断、不改字：它逐句读中英对照，把疑似对错位的行标红，改不改由人决定。
> AI 重对齐更严格——只让模型输出句子编号的分组，程序校验编号必须不重不漏地
> 覆盖全部句子，然后按编号回填**原句**。模型碰不到正文一个字。

## 五、自己打包

```bash
pip install -r requirements.txt -r desktop/requirements-build.txt
python -m desktop.selftest      # 冒烟测试，22 项
pyinstaller desktop/build.spec --noconfirm
```

产物在 `dist/`。跨平台交叉编译做不到——Windows 的 `.exe` 只能在 Windows 上打；
仓库里的 `.github/workflows/build-desktop.yml` 就是干这个的，推上去让 GitHub
的 macOS 和 Windows 机器各打一份。

## 六、代码结构

```
desktop/main.py        入口：起本机服务 + 开浏览器
desktop/settings.py    密钥读写（用户目录，不进程序包）
desktop/webui.py       设置页路由
desktop/selftest.py    冒烟测试
desktop/build.spec     打包配置
app/align.py           切句、两档打分、动态规划对齐、AI 校验与重对齐
app/clean.py           清洗规则
app/ocr.py             扫描件识别
app/export.py          各种导出格式
app/server.py          Flask 路由
app/templates/         界面
```

同一套 `app/` 也是网页版在跑的代码，桌面版只是换了个入口、关掉了检索与账号
那部分（见 `config.DESKTOP`）。
